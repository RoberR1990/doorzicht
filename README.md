# Doorzicht

Zie wat verstopt zit. Een experiment van Parkeren, Stadsbeheer: droge, versnipperde informatie over een parkeergarage samengebracht op één visuele plek, in 3D.

Alle gegevens zijn dummydata of open data. De garage, gebouwen en cijfers zijn fictief.

Gemaakt door Robert Riteco, Productmanager Data bij Stadsbeheer, afdeling Parkeren.
